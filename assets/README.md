# IBM 3270 display font

`3270-Regular.ttf` is from the upstream `3270font` v3.0.1 release:

- Project: <https://github.com/rbanffy/3270font>
- Release: <https://github.com/rbanffy/3270font/releases/tag/v3.0.1>
- License: BSD 3-Clause; see [`LICENSE.txt`](LICENSE.txt).

The upstream project documents that its design derives from the x3270 font,
itself transcribed from a physical IBM 3270-series terminal. The GUI rasterizes
this font into the 5251 screen texture; it is a 3270-style font, not the
unavailable original 5251 character-generator ROM.
